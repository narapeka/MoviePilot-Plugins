# MoviePilot-Plugins

在 MoviePilot 的插件市场设置中添加仓库地址：

```text
https://github.com/narapeka/MoviePilot-Plugins
```

仓库分别提供 `package.v2.json` / `plugins.v2` 与
`package.v3.json` / `plugins.v3`，由 MoviePilot 选择对应版本。
插件直接从源码安装，无需手动替换容器内文件。

## 文件名多级分类

V2 保留原有 1.0 版；V3 提供独立的 3.0.0 版，使用 V3 SDK 和整理事件接口。
V3 适配基线为 MoviePilot 3.1.7。

规则格式、先后顺序、`{年代}`、`{首字母}` 和原分类下追加子目录的行为保持不变：

```text
#CHD|CHDBits#CHDBits/原盘
/downloads##{年代}
/我的接收#UHD|4K#4K/{首字母}
```

路径条件是目标路径的包含匹配，文件名关键字支持不区分大小写的正则表达式。
V3 使用源文件项或源路径取得原始文件名，仅通过事件输出改写整理路径，
不修改主程序传入的原始媒体对象。

设备状态检测（DeviceCheck）已从仓库下架。已安装的实例不会自动卸载，
需要在 MoviePilot 中自行停用或卸载。

## 115直链缓存修正

本补丁适用于 CDN 直链有效期较短、疑似复用过期直链导致播放或续播失败的情况。
**原插件使用正常时不建议开启**；本补丁不会延长 CDN 直链的有效期。

V2 / V3 分别提供独立实现，安装对应版本的官方 115网盘STRM助手后再启用本插件。
本插件不需要 115 Cookie、Open Token 或其他账号配置，也不直接请求 115 接口。
点击插件卡片直接打开配置，当前接管状态也在配置页显示，不提供单独的状态页。

- **限时缓存**：默认最长 15 分钟，可选择 15 分钟、30 分钟、1 小时、2 小时、6 小时、12 小时。
  实际到期时间取“本次获取时间 + 所选时长”“原插件提供的到期时间”
  和“CDN URL 的 `t` 减 300 秒”三者最早值，读取不续期。
- **跳过缓存读取**：用于排查问题，每次请求仍由原插件解析链接，会增加接口请求。
  仍保留有效条目的计数，供原插件的多端播放逻辑使用。
- 每次读取和多端计数都检查条目内的绝对到期时间，不依赖宿主缓存后端的 TTL 正确性。
  底层统一保留最多 24 小时，最大条目数仍由原插件的缓存实例限制。
- 使用独立缓存区域，不导入无获取时间的旧直链，也不清除其他业务数据。
  CDN URL 没有可解析的 `t` 或已到安全截止时间时不缓存，原插件仍照常返回该 URL。
- 在配置窗口点击保存后生效，无需重启 MoviePilot 或原插件；单独拨动开关但未保存不会生效。
  已发出的 CDN 地址和正在进行的请求不被改写，后续经过 302 服务的请求使用新策略。
- 目标插件正常重载后通过 `PluginReload` 事件重新接管；停用本插件恢复原方法。
  原插件清空 302 缓存时，同时清空本插件的缓存区域。
- 无需重建 STRM。账号、目录、数据库和原插件文件不变，原来的请求锁继续生效。

本插件只针对标准实例 `P115StrmHelper`，不接管其虚拟分身。
接管不兼容时会在日志和插件页面显示原因并保留原方法。
这是对原插件内部方法的补丁，未来上游重构后可能需要更新本插件。
不会延长 115 服务端链接有效期，也不会自动识别或修复播放端的 HTTP 403。
不修改 STRM 生成、同步、整理和刮削逻辑；所有使用该 302 服务的请求
（包括分享链接播放、读取媒体信息等）都会采用新缓存策略，多端播放计数也以有效条目为准。
